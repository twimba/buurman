# Buurman Marketing Website

A professional single-page marketing website for Buurman property management platform.

## What's Included

✅ **Hero Section** - Eye-catching headline with clear call-to-action
✅ **What is Buurman** - Clear explanation of the product
✅ **Features Section** - 6 key features with screenshot placeholders
✅ **Pricing Section** - 3 pricing tiers (Basic, Big, Mega) with all details
✅ **Testimonials** - 6 realistic customer testimonials
✅ **CTA Section** - Strong call-to-action with contact information
✅ **Responsive Design** - Works perfectly on mobile, tablet, and desktop

## Features

- **Single HTML file** - No dependencies, easy to deploy
- **Modern Design** - Professional gradient design matching the app
- **Fully Responsive** - Mobile-first approach
- **Fast Loading** - Inline CSS, no external resources
- **SEO Friendly** - Proper meta tags and semantic HTML

## Deployment

Simply upload `index.html` to your web server or hosting platform:

```bash
# Copy to web server
scp index.html user@server:/var/www/html/

# Or deploy to static hosting
# - Netlify: Drag and drop
# - Vercel: vercel deploy
# - GitHub Pages: Push to gh-pages branch
```
